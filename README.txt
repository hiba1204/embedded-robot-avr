
* ========== I/O IDENTIFICATION (CONNEXIONS ON THE ROBOT) =============
 *
 * ┌───────────────────────────────────────────────────────────────────┐
 * │                    ATmega324PA - Pinout                           │
 * ├───────────────────────────────────────────────────────────────────┤
 * │                                                                   │
 * │   PORTA            PORTB          PORTC          PORTD            │
 * │  ┌───────┐     ┌──────┐           ┌──────┐       ┌──────┐         │
 * │  │ PA0 ●─│→S1  │PB0 ○ │           │PC0 ●─│→SCL   │PD0 ●─│→RXD     │
 * │  │ PA1 ●─│→S2  │PB1 ○ │           │PC1 ●─│→SDA   │PD1 ●─│→TXD     │
 * │  │ PA2 ●─│→S3  │PB2 ●─│→P-GND     │PC2 ●─│→LED-G │PD2 ●─│→B       │
 * │  │ PA3 ●─│→S4  │PB3 ●─│→P-PWM     │PC3 ●─│→LED-R │PD3 ○ │         │
 * │  │ PA4 ●─│→S5  │PB4 ●─│→PG+       │PC4 ○ │       │PD4 ●─│→PWM-L   │
 * │  │ PA5 ●─│→DS  │PB5 ●─│→PG+       │PC5 ○ │       │PD5 ●─│→PWM-R   │
 * │  │ PA6 ○ │     │PB6 ●─│→PG+       │PC6 ○ │       │PD6 ●─│→D-L     │
 * │  │ PA7 ○ │     │PB7 ●─│→PG+       │PC7 ○ │       │PD7 ●─│→D-R     │
 * │  └───────┘     └──────┘           └──────┘       └──────┘         │
 * │                                                                   │
 * │  ● = USED          ○ = UNUSED                                     │
 * └───────────────────────────────────────────────────────────────────┘
 * LEGEND :
 * PG             : SPI (Programmer)
 * RXD/TXD        : UART (debug)
 * SCL/SDA        : EEPROM externe
 * B              : interrupt button 
 * LED-R/G        : green/red LED
 * P-PWM/P-GND    : piezo
 * S1-S5          : line sensors
 * DS             : distance sensor
 * PWM-L/R, D-L/R : left/right motors
 * =====================================================================
